AndryushaExplorer

Файловый менеджер для облачных хранилищ / Cloud storage file manager

AndryushaExplorer — настольное приложение для работы с файлами в облачных хранилищах, включая Google Drive: просмотр, загрузка, скачивание, копирование и перемещение файлов между облаками и компьютером.

AndryushaExplorer is a desktop application for managing files in cloud storage services, including Google Drive: browse, upload, download, copy and move files between clouds and your computer.

Приложение предназначено для внутреннего использования небольшой командой. / The app is intended for internal use by a small team.
